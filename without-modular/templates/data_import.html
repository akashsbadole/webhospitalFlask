Import Guidelines
CSV Format Requirements:
  • Required fields: first_name, last_name
  • Optional fields: email, phone, date_of_birth, gender, address, etc.
  • Date format: YYYY-MM-DD
  • First row should contain column headers
HL7 FHIR Format:
  • Must be a valid FHIR Bundle
  • Patient resources will be imported
  • Observation resources will be imported as medical records
Warning: Always validate your data before importing. Duplicate patient IDs will be skipped.
